# FitPack

Готовый статический сайт для GitHub Pages.

## Google Analytics
В сайт встроен GA4 Measurement ID:
G-87TZQZ8MR4

## Структура
- index.html — главная
- nutrition.html — питание
- weight-loss.html — похудение
- training.html — тренировки
- supplements.html — добавки
- articles/ — статьи
- css/style.css — оформление

## Публикация
Загрузите содержимое папки в GitHub repository и включите Settings → Pages → Deploy from branch → main → / (root).
